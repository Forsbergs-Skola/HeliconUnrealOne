# Intro Cutscene

## Overview

The Intro Cutscene establishes the atmosphere before the player gains control.

It introduces the environment and creates the initial mood while preventing player interaction during the sequence.

## Purpose

Rather than immediately placing the player into gameplay, the cutscene provides visual storytelling and prepares the player for the game's narrative.

It also allows the environment to be introduced in a controlled and cinematic way.

## Implementation

The cutscene is created using Unreal Engine's Level Sequencer.

The sequence includes:

- Multiple Cine Cameras
- Camera Cuts
- Camera Fades
- Animated camera movement

Player movement and interaction are disabled while the sequence plays.

Once the sequence has finished, player control is automatically restored.

## Advantages

- Strong narrative introduction.
- Smooth transition into gameplay.
- Controlled player experience.
- Easily editable using Sequencer.****
