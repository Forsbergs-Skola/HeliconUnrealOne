# Board Puzzle Documentation #
## Description ##
The board puzzle is a puzzle where the player has to unlock nodes in the correct order to complete a full board and progress in the room.

## Actors ##
### BoardPuzzleNode ###

The board puzzle node actor is the actor the player has to interact with by clicking the left mouse button on it's sphere collider.
That triggers the node to unlock it's owned link or if it is the final node, checks if the board was completed correctly.
